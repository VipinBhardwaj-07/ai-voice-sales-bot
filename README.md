# 🎙️ AI Voice Sales Bot (Aria)

An AI sales agent that holds a **real voice conversation** with a customer, shows the chat live, records the call, and then produces an **AI summary and a sales status**. Built for the Sankar Group intern assignment.

**Live demo:** https://YOUR-PROJECT.vercel.app  
**Repository:** https://github.com/VipinBhardwaj-07/ai-voice-sales-bot

---

## ✨ Features

| Area | What it does |
|------|--------------|
| 🗣️ Voice conversation | Aria speaks, listens, answers questions, explains the product and tries to convert the customer |
| 🌐 Languages | English and Hindi (हिन्दी) |
| 💬 Live transcript | Customer and bot messages appear as text in real time, including partial speech |
| 📞 Call controls | Start Call, End Call, Mute, Hold, Speaker, call timer and live status |
| 🎤 Microphone check | Enable Microphone button with a live level meter and clear error messages |
| ⏺️ Recording | Saved after the call with an explicit consent checkbox, with playback and download |
| 🧠 AI summary | Short summary, customer requirements, objections, next steps, lead score, sentiment |
| 🏷️ Sales status | Converted · Interested · Follow-up Required · Not Interested · Demo Requested · No Response |
| 🕘 Call history | Every call with recording, summary, full word-for-word transcript and status |
| 📊 Analytics | Total calls, conversions, average lead score, talk time, pipeline by status, CSV export |
| 📈 Live insights | Buy-intent gauge, sentiment, conversation stage tracker, Sales Radar notes |
| 🛠️ Product setup | Change the product name, features and pricing to sell **any SaaS product** |

## ✅ Assignment requirements checklist

1. **Voice conversation** – browser speech recognition and speech synthesis, replies generated by Claude
2. **Language** – English and Hindi
3. **Live chat screen** – Live Transcript panel
4. **Call controls** – Start Call / End Call buttons, duration and status
5. **Call recording** – consent required, saved and playable after the call
6. **AI summary** – generated automatically when the call ends
7. **Sales status** – one of the six required statuses, assigned automatically
8. **Call history** – recordings, summaries, transcripts and final statuses

## 🧱 Tech stack

- **Frontend:** a single `index.html` with plain HTML, CSS and JavaScript (no build step)
- **Voice:** Web Speech API (`SpeechRecognition` and `speechSynthesis`)
- **Recording:** `MediaRecorder` and Web Audio API (waveform and level meter)
- **AI:** Anthropic Claude through the Messages API
- **Backend:** one serverless function (`api/chat.js`) that keeps the API key private
- **Storage:** IndexedDB in the browser (calls, audio, transcripts)
- **Hosting:** Vercel

## 🔄 How it works

```
Customer voice → Browser speech-to-text → /api/chat → Claude
       ↑                                                  │
 Browser text-to-speech ←── next sales line + live insights
```

1. The customer ticks the consent box and presses **Start Call**. The microphone starts recording.
2. Aria greets the customer. The browser converts the customer's speech to text.
3. Each turn is sent to `/api/chat`. Claude returns Aria's next line plus sentiment, buy intent, stage and a key point.
4. When the call ends, Claude writes the summary, requirements, objections, next steps, lead score and picks one of the six statuses.
5. The call is saved in IndexedDB and appears in **Call History**.

## 🚀 Run locally

Requires **Node.js 18+**.

```bash
git clone https://github.com/VipinBhardwaj-07/ai-voice-sales-bot.git
cd ai-voice-sales-bot
cp .env.example .env      # then add your ANTHROPIC_API_KEY
npm start
```

Open http://localhost:3000 in **Chrome or Edge**.

## ☁️ Deploy to Vercel

1. Import the GitHub repository in Vercel (framework preset: **Other**).
2. Add the environment variable `ANTHROPIC_API_KEY`.
3. Click **Deploy**. Vercel serves the site over HTTPS, which the microphone requires.

### Environment variables

| Name | Required | Description |
|------|----------|-------------|
| `ANTHROPIC_API_KEY` | Yes | Your key from console.anthropic.com |
| `MODEL` | No | Claude model to use (default `claude-haiku-5-5`) |

## 🧪 Using the app

1. Open the site in desktop Chrome or Edge and click **Enable Microphone**.
2. Choose English or Hindi, tick the recording consent box, and press **Start Call**.
3. Talk to Aria, ask about price, and try raising an objection.
4. Press **End Call** to see the summary and status.
5. Open **Call History** to replay the recording and read the full conversation.

## ⚠️ Notes and limitations

- Use **headphones** so Aria's voice does not leak into the recording.
- Speech recognition works best in Chrome and Edge. Safari and Firefox support it poorly. A typed-reply box is available as a fallback.
- Hindi voice quality depends on the voices installed on the device.
- Call history is stored **per browser**. Add a database if you need shared history.
- Keep your API key only in Vercel's environment variables. Never commit `.env`. Set a spending limit on the key.
